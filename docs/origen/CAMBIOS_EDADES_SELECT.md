# Ajuste de edad en administración

Los campos Edad mínima y Edad máxima del producto ahora son listas desplegables con edades predefinidas. Persisten números de meses como antes, por lo que no requieren cambios en la base de datos. Los valores de productos anteriores se conservan, incluso si no coinciden con las opciones estándar. Incluye validación para evitar edades invertidas.
