# Baby Center · Ajuste de alineación / ensayo conservador

Se conserva el proyecto anterior (backend, base de datos, buscador, administración, carrito y banners).

Cambios visuales:
- Retirada la sección independiente de dos tarjetas «Mundo Bebé / Mundo Kids» que competía con el hero.
- Restaurado el menú principal aprobado (sin dos enlaces añadidos).
- Incorporado un selector compacto «Bebés / Kids y juguetes» **dentro del encabezado de Categorías**.
- Se mantiene el mismo ancho de contenedor `.wrap.w`, tipografías y colores.
- El selector usa la acción `world` preexistente y dirige a los productos filtrados.

Límites: la clasificación actual de Kids depende de las categorías existentes; no se han inventado edades ni modificado la base de datos.

Ejecución: entrar a `babycenter/`, ejecutar `npm install` y `npm start`; abrir `http://127.0.0.1:3000/`. Mantener abierta la terminal.
