# Baby Center: menú Bebé / Kids

Se conserva la composición, el hero y la identidad del sitio aprobado.

- Menú: Inicio, Mundo Bebé (categorías dinámicas), Mundo Kids (categorías dinámicas), Juguetes y Ofertas.
- En móvil el menú se muestra en una fila horizontal compacta.
- Las categorías de cada mundo provienen de los productos publicados; las vacías no aparecen.
- Mundo y categoría se combinan para filtrar productos. Juguetes busca coincidencias en nombres y categorías.
- Se mantienen administrador, selectores de edad, buscador y carrito.

Nota: El filtro Juguetes reconoce palabras frecuentes en el nombre o categoría. Para clasificación exacta de juguetes a futuro conviene un campo de tipo de producto independiente del mundo.
