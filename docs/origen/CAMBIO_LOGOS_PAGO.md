# Logotipos de pagos

Se instalaron como recursos locales en `public/img/payments/`: Visa, Mastercard, PSE, Nequi, Addi y Sistecrédito, a partir de las imágenes aportadas por el cliente. Las imágenes se redimensionan sin deformarse.

La presencia del logotipo NO habilita ni certifica métodos de pago: el cobro real sigue condicionado a la integración, habilitación del comercio y confirmación del proveedor.
