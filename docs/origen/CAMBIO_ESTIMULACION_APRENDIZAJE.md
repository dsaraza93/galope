# Estimulación y aprendizaje

Se incorporó acceso en menú principal conservando el diseño. El enlace filtra el catálogo por términos educativos y de estimulación en nombre, descripción y categoría. Se agregó una categoría administrable Estimulación y aprendizaje al selector de productos.

Los productos existentes mantienen sus categorías y edades; los nuevos se pueden clasificar en la categoría específica. No se modificó la base de datos existente. La categoría utiliza provisionalmente una imagen de Juegos hasta que el cliente suministre una propia.
