# Galope · Workers + D1 + R2

Esta es la versión principal de la tienda. Conserva la API, inventario, administración, clientes, campañas y checkout Bold de la tienda, con identidad y catálogo llaneros.

- [Inicio, funcionalidades y desarrollo local](../README.md)
- [Preparación de recursos y despliegue futuro](../DESPLIEGUE.md)
- [Validación de esta adaptación](VALIDACION.md)
- [Contratos de API](API.md)

El proyecto utiliza recursos propios de Galope. El despliegue inicializa automáticamente los ajustes faltantes y carga ejemplos solo en una tienda nueva. Los ejemplos tienen stock cero y los banners comienzan ocultos. Pruebas con datos ficticios y compilación no equivalen a certificación de pagos.
